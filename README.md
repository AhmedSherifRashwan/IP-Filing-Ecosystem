# IP Filing Ecosystem

Private workspace for the **Patent Drafting Prompt Playbook** and the seven-agent drafting architecture that executes it.

- [PLAYBOOK.md](PLAYBOOK.md) — the full playbook: 8 phases / 40+ prompts, master prompts, the 14-question filing gate, loop-back rules, and Part C (the seven-agent architecture).
- `dossiers/` — one versioned Invention & Drafting Dossier per matter (never committed; see `.gitignore`). Inventor disclosures are confidential.

> AI drafting is a drafting and analysis aid, not a substitute for jurisdiction-specific advice from a qualified patent attorney or patent agent.
